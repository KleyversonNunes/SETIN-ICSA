# DOCUMENTAÇÃO DO SETIN/ICSA

O presente repositório serve como documentação sobre os serviços ofertados pelo Setor de Informática (SETIN) do Instituto de Ciências Sociais Aplicadas (ICSA) da UFPA.  
Nesse repositório será documentado a estrutura de serviços e assuntos, atendidos pelo SETIN, além de guias com dúvidas frequentes que professores e técnicos do ICSA costumam apresentar e por fim uma seção apenas com tutoriais que mostram formas de resolver problemas recorrentes que chegam até o SETIN.  

## Sagitta
A partir de Julho de 2026, será adotada uma nova estrutura de serviços e assuntos atendidos pelo SETIN, veja a comparação entre antiga estrutura e a nova. Clique no [link](sagitta/estrututa_sagitta.md) para visualizar.
