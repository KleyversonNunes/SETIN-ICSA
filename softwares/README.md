# SOFTWARES
Os programas utilizados pelo Setor de Informática (SETIN) do ICSA, se enquadram em três categorias principais: gerenciais, administrativos e laboratórios.

## [Gerenciais](./gerencias/)
Nessa categoria ficam os programas utilizados pelo SETIN, para gerenciar o parque computacional do instituto, entre eles temos:
- **Action1**: um SAAS para gerenciar computadores com sistema operacional Windows.
- **Ansible**: uma plataforma de automação de TI, de código aberto, desenvolvida pela RedHat. Utiliza ssh e Python para esse fim. Serve exclusivamente para ambiente Linux.
- **SSH e Rustdesk**: utilizados para realizar suporte remoto, aos usuários (servidores e bolsistas) do instituto.

## [Administrativos](./administrativos/)
Nessa categoria ficam os programas comuns utilizados nos setores administrativos: secretarias, CPGA, almoxarifado, entre outros. Os programas mais comuns são: Suíte de Escritório (Only Office, Libbre Office), navegadores (Chrome, Firefox, Edge), 7zip, entre outros.

## [Laboratórios](./laboratorios/)
Nessa categoria ficam os programas mais específicos, pois cada faculdade terá programas específicos para determinadas disciplinas. Por exemplo, a Faculdade de Economia utiliza muito o R/R Studio. A faculdade de Arquivologia utiliza um sistema web de acervos arquivísticos chamado AtoM (Access to Memory). Já a faculdade de Contabilidade depende bastante dos programas da Receita Federal como IRPF, DIRF, GCAP, DCTF, além de sistemas de gestão contábil como o Fortes AC.
